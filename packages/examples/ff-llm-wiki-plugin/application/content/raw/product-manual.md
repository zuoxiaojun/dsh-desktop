# 用户操作手册（v2.3）

> 面向最终用户的使用说明，描述功能入口、操作路径与常见问题的自助解法。

## 背景

手册随版本迭代更新，v2.3 覆盖了资料中心、Wiki 阅读器两类核心界面的操作路径。
手册同时是客服话术与满意度指标的上游依据：客服回答以手册为准，偏差即缺陷。

## 关键结论

- 每个功能的操作路径必须唯一且可复现，避免多入口造成认知负担。
- 常见问题（FAQ）要沉淀为可检索条目，减少重复人工答疑。
- 用户反馈应回流到需求池，形成「使用 → 反馈 → 迭代」闭环。
- 手册与产品承诺的服务水平保持一致，承诺能力必须可自助验证。

## 关联

本文档与客服话术手册共享大量术语，是客服知识库的产品侧源头。
