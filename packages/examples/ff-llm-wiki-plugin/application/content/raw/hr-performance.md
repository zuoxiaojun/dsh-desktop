# 绩效考核管理办法（2025）

> 定义绩效目标设定、过程反馈、结果评定与晋升挂钩的规则。

## 背景

绩效管理是把组织目标分解到个人的机制。管理办法要求目标可衡量、过程有反馈、结果可申诉，
绩效结果与晋升、培训投入直接挂钩。

## 关键结论

- 绩效目标必须可衡量，过程反馈常态化而非一年一次。
- 绩效结果与晋升评审直接挂钩。
- 培训投入向绩效短板倾斜，形成能力提升闭环。
- 考勤与合规表现纳入绩效综合评定。

## 关联

本文档与晋升评审、培训体系、考勤制度共同构成人力发展闭环。
