# 数据泄露应急预案

> 定义数据泄露事件发生后的响应步骤、职责分工与恢复策略。

## 背景

数据泄露是典型的高影响安全事件。预案要求事件发生后先止损、再溯源、后复盘，
全程记录时间线。监控告警是发现泄露的第一道信号，恢复后要更新保留与销毁策略。

## 关键结论

- 事件响应先止损、再溯源、后复盘，避免扩大影响。
- 安全监控与告警是泄露发现的第一道信号。
- 泄露后必须复盘并更新数据保留与销毁策略。
- 响应过程全程记录时间线，供合规审计追溯。

## 关联

本文档与信息安全制度、监控告警体系、数据保留策略强相关。
