# 权限与合规管理

> 定义账号权限的授予、复核、回收机制与合规审计要求。

## 背景

权限管理是信息安全的执行层。权限授予遵循最小权限，账号离岗必须及时回收，
权限变更定期复核。合规审计以日志与授权记录为证据，接口鉴权同样遵循这一原则。

## 关键结论

- 权限授予遵循最小权限，默认拒绝、按需授权。
- 账号权限定期复核，离岗必须及时回收。
- 合规审计以授权记录与日志为证据。
- 接口鉴权同样遵循最小权限，只暴露必需能力。

## 关联

本文档是信息分级、接口安全与合规审计的执行依据。
