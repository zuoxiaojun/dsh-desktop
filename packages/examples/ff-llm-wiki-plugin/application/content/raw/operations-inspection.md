# 服务器巡检手册（每周点检）

> 定义服务器每周巡检的检查项、判断标准与异常处置方式。

## 背景

巡检是发现隐患的前置手段，覆盖资源水位、进程状态、日志异常等维度。巡检结果要与
监控告警联动，异常项进入工单跟踪，重保时期提高巡检频次。

## 关键结论

- 巡检覆盖资源、进程、日志等维度，异常项进入工单跟踪。
- 巡检结果与监控告警联动，形成隐患闭环。
- 容量水位是巡检重点，逼近阈值时提前扩容。
- 备份有效性需在巡检中验证，不能只看备份任务是否成功。

## 关联

本文档与监控告警体系、容量规划、备份恢复共同构成运维日常。
