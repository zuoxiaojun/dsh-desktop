# 客服话术手册（常见问题处理）

> 汇总高频问题的标准答复口径，是客服一线应答与知识库条目的统一来源。

## 背景

话术手册把高频问题沉淀为标准答复，减少一线客服的临场发挥。答复口径以产品操作手册为准，
产品能力变化时话术同步更新。话术条目同时用于工单分类与自助服务。

## 关键结论

- 高频问题必须沉淀为标准话术，答复口径全团队统一。
- 话术以产品操作手册为上游依据，偏差即产品缺陷。
- 首次响应必须在约定时限内给出，不能「已记录」了之。
- 疑难问题按升级标准转交，不在一线反复空转。

## 关联

本文档与投诉处理流程、服务 SLA 共同定义客服的知识结构。
