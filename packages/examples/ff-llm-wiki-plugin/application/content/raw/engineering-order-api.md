# 接口文档（订单中心 v1.8）

> 订单中心对外接口的字段定义、版本策略与鉴权要求，是联调与集成的契约。

## 背景

订单中心对外提供下单、查询、取消等接口。接口文档是前后端联调的唯一契约，
字段变更必须走版本策略，避免破坏既有调用方。鉴权由网关统一完成，订单中心只校验业务权限。

## 关键结论

- 接口以版本化契约交付，破坏性变更必须升级主版本号。
- 鉴权下沉到网关，业务侧只做细粒度权限校验。
- 对外接口必须同时提供错误码与幂等语义。
- 联调以文档为准，口头约定一律无效。

## 关联

本文档与网关架构、权限管理策略共同约束接口的交付方式。
