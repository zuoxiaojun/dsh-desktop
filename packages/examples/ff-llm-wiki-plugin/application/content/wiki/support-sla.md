# 服务等级协议

> 响应时限与解决时限的量化承诺。

## 结论

SLA 分别定义首次响应时限与解决时限并量化考核。

SLA 承诺与产品能力对齐，避免过度承诺。

## 来源证据

- **服务 SLA 与满意度说明**（`raw/support-sla.md` · 客服部）
  - SLA 承诺必须与产品能力对齐，避免过度承诺。
  - 首次响应时限与解决时限要分别定义并量化考核。
  - 满意度按工单抽样度量，低分样本必须回溯根因。
  - 变更窗口等服务行为要避免落在 SLA 承诺的高峰期。
- **用户操作手册（v2.3）**（`raw/product-manual.md` · 产品部）
  - 每个功能的操作路径必须唯一且可复现，避免多入口造成认知负担。
  - 常见问题（FAQ）要沉淀为可检索条目，减少重复人工答疑。
  - 用户反馈应回流到需求池，形成「使用 → 反馈 → 迭代」闭环。
  - 手册与产品承诺的服务水平保持一致，承诺能力必须可自助验证。
