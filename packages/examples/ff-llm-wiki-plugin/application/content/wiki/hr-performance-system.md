# 绩效管理体系

> 目标设定、过程反馈与结果评定。

## 结论

绩效目标可衡量，过程反馈常态化而非一年一次。

绩效结果与晋升、培训投入直接挂钩。

## 来源证据

- **绩效考核管理办法（2025）**（`raw/hr-performance.md` · 人力资源部）
  - 绩效目标必须可衡量，过程反馈常态化而非一年一次。
  - 绩效结果与晋升评审直接挂钩。
  - 培训投入向绩效短板倾斜，形成能力提升闭环。
  - 考勤与合规表现纳入绩效综合评定。
- **培训课程与晋升评审**（`raw/hr-training.md` · 人力资源部）
  - 培训课程按能力阶梯设计，覆盖岗位全周期。
  - 晋升评审以绩效与能力双重证据为依据。
  - 安全培训是全员必修项，不因岗位豁免。
  - 招聘标准与能力标准对齐，保证入口质量。
