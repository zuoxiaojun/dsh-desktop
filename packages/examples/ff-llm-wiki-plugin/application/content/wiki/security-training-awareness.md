# 安全培训与意识

> 全员安全意识培训的落地。

## 结论

安全培训是全员必修项，不因岗位豁免。

培训与入职流程衔接，底线要求前置传递。

## 来源证据

- **信息安全管理制度（2025 版）**（`raw/security-policy.md` · 安全部）
  - 信息按敏感程度分级，分级决定保护强度与访问范围。
  - 访问控制遵循最小权限，默认拒绝、按需授权。
  - 数据泄露等安全事件必须走既定应急响应流程。
  - 全员安全意识培训是制度落地的必要条件。
- **培训课程与晋升评审**（`raw/hr-training.md` · 人力资源部）
  - 培训课程按能力阶梯设计，覆盖岗位全周期。
  - 晋升评审以绩效与能力双重证据为依据。
  - 安全培训是全员必修项，不因岗位豁免。
  - 招聘标准与能力标准对齐，保证入口质量。
