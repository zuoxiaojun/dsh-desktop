# Agent Note: 插件恢复运行清单差异安全模式

Status: implemented

[English](2026-08-24-plugin-recovery-safe-mode.md) | 中文

## 问题

Desktop 完整捕获旧环境快照后，插件安装仍可能失败。恢复随后可能成功还原 Profile 文件与依赖，并重新启动通过环回健康检查的 Host，但在最后比对 Loader 条目、客户端模块或 Skill 确定清单时失败。持久日志会记录 `runtime-verification-failed`；过去的启动闸门会把它与快照不可读或依赖恢复失败同等处理，后续每次启动都只能打开独立恢复页。

Issue #22 提供的 Windows 诊断包含一次 `package-mutation-failed` 安装和后续 14 次恢复尝试。每次尝试都经过 Profile 恢复、依赖恢复、Host 重启与运行验证，最后以相同原因失败。重新安装应用不会删除用户数据中的日志，因此替换二进制文件无法释放启动闸门。即使 Host 已健康到可以承载插件中心，用户也只有无法收敛的重复重试操作。

## 决策

恢复过程会分开 Host 健康与确定运行证据。无法响应环回健康请求会记为 `host-start-failed`，并继续作为硬恢复失败；`runtime-verification-failed` 表示健康检查已通过，只有规范化 Loader／客户端／Skill 清单不一致。

启动时，只有持久的 `runtime-verification-failed` 快照可以进入插件安全模式。Desktop 会直接用已恢复 Profile 启动 Host，不运行普通应用更新迁移，用正常渲染器直接打开插件中心，保留恢复状态卡，并自动展开已安装管理器。日志不可读，以及快照、Profile、依赖、锁或 Host 失败时，独立恢复页仍是唯一界面。

安全模式实行双重约束。渲染器会禁用目录安装和已安装插件的更新／启用，同时保留配置、恢复重试、诊断导出、停用与卸载；主进程 IPC 会独立解码每个请求，只接受 `disable` 或 `uninstall`，伪造的安装、更新或启用请求会被拒绝。两项允许操作都会减少或移除第三方运行权限，并继续走普通管理使用的快照、Host 换代、验证与恢复事务。

恢复重试成功或安全模式管理操作提交后，启动限制会清除。重试若变为硬恢复原因，界面会返回受保护恢复页。重新安装应用仍然不会破坏用户数据，但健康 Host 不会再被困在只能无限重试的页面之后。

## 考虑过的替代方案

**让每种恢复失败都进入安全模式。** 否决，因为损坏快照、不完整依赖恢复、活动 Profile 锁或不健康 Host 无法可靠承载插件中心。

**运行清单不一致后启动完整普通产品。** 否决，因为用户移除原因之前，对话与其他工作流可能执行发生差异的运行能力。安全模式只打开插件中心，并收窄变更权限。

**忽略证据差异，把旧日志改写成 `rolled-back`。** 否决，因为 `rolled-back` 承诺旧证据已经验证。安全模式保留失败记录，并要求同事务重试完全收敛，或执行新的、经过验证的停用／卸载事务。

**重新安装应用时删除插件日志。** 否决，因为卸载二进制文件不能静默丢弃恢复证据或用户 Profile 状态，也不能证明插件环境安全。

## 后果

用户可以检查已安装插件，并移除或停用可能的故障来源，不必重复恢复同一份无法收敛的清单。安全清理会用新的恢复事务取代终态失败日志；目标状态与无关连续性证据通过后，普通插件操作会恢复。

安全模式分类依赖 `runtime-verification-failed` 表示 Host 健康检查已经通过。因此恢复控制器分别拥有健康与证据失败映射，后续修改不能再次把两项观测合并为同一个原因。

新的诊断导出会增加 Desktop 版本和支持平台，同时继续记录稳定阶段与原因，而不是原始本地路径或错误对象。更细的脱敏 expected／observed 清单差异属于独立支持改进，不是安全进入或清理的必要条件。

## 测试

Desktop 崩溃恢复测试使用真实日志，固定只有运行清单差异会启动安全 Host，Profile 与不可读日志失败仍会硬阻断，并固定仅停用／卸载的动作分类。恢复控制器测试固定健康／证据区分和同事务重试收敛。插件中心组件测试固定安全模式标题与说明、自动展开已安装管理器、更新禁用、停用／卸载可用、卸载确认交接、重试和诊断导出。诊断测试固定新增 Desktop 版本与平台，同时确保不暴露 Profile 路径或 canary 内容。无密钥构建产物 Web 组合会用 14 次运行清单差异挂载真实插件中心客户端，并证明普通页面展示安全模式的已安装管理器。打包前会分别编译 Desktop 与插件中心 TypeScript 程序。
