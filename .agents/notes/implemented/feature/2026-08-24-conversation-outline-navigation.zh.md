# Agent Note: 完整对话目录导航

Status: implemented

[English](2026-08-24-conversation-outline-navigation.md) | 中文

## 问题

ChatView 初始只渲染最近 50 条消息，并通过显式向前分页扩展窗口。长会话因此需要重复加载页面并手动扫描，读者才能回看较早的提问、回答或 Tool 调用。仅从已挂载 DOM 行派生的目录仍会保留这一限制；而预先挂载完整正文，则会让目录发现与每一条历史记录的 Markdown、Tool 卡片、图片和布局工作争夺资源。

导航界面还必须保留已寻址 subagent 的传输方式。子会话正文通过目录派生的 `SubagentAddress` 读取；对该视图使用普通会话历史，会绕过 sessions 领域已经保留的路由事实。

## 决策

内置 ChatView 拥有一个会话本地的右侧目录。它索引持久来源为人类的 append-origin 用户消息、可见的助手消息，以及根 `tool/call` 事件。每个项目都携带渲染行序列、用户／助手／工具角色，以及规范化且不超过 80 个字符的单行摘要。工具摘要只包含 Tool 名称而不包含参数，因此目录导航不会成为第二个暴露调用参数的位置。

目录独立于已渲染正文读取完整历史。普通会话以每次 50 条消息的请求分页调用 `session.history`；已寻址子会话则携带保留的 mode-bearing address 调用 `subagent.history`。该读取只构建序列、角色和摘要，不会修改 Session 事件窗口。当前已组装的 Chat 节点会覆盖合并到持久索引中，因此新增或流式输出的尾部无需重新扫描完整日志也会出现。

每个 Chat 行都会在稳定 key 旁发布 `data-chat-anchor-seq`。选择已挂载的目录项时，界面按该序列平滑滚动到对应行。选择未加载项目时，界面会串行调用现有 `loadOlder()`，等待每一页完成 React 提交，再重复执行，直到目标出现或历史停止前进。定位成功后，面板会在滚动前自动收起，并以适配主题的 2.2 秒高亮标记完整正文行；目录仍是导航而非第二套全文阅读器，但所属正文中的目标会明确可见。更新的选择会使之前的跳转失效；组件卸载会使所有待处理跳转与高亮失效。

展开面板渲染固定 48px 高度的行窗口并带有 overscan，而不是为每条历史建立 DOM 行。收起状态的侧轨最多抽样 80 个按角色着色的标记。活跃标记会在滚动时，以及打开、prepend 或插入尾部之后，跟随第一条可见的稳定正文行。悬停收起侧轨只负责打开面板，收起与隐藏则由显式控件完成；指针离开不会自动收起，因为展开会改变预留间距，若让 enter／leave 绑定该 reflow 就会循环振荡。展开面板会为正文预留右侧间距；隐藏后只保留一个显式恢复控件。该界面使用共享主题 token，并在宽度低于 760px 时省略，因为桌面宽度的导航姿态在该范围内会过度压缩消息列。

## 考虑过的替代方案

**只索引已挂载的 Chat 行。** 否决，因为目录会漏掉最需要导航的较早内容，用户仍要反复手动点击「加载更早」。

**打开目录时把所有历史页载入 Session 窗口。** 否决，因为完整正文渲染会执行轻量索引所规避的 Markdown 与 Tool 卡片工作，并在用户请求跳转之前改变阅读位置。

**把正文替换为通用虚拟聊天列表。** 暂缓，因为它会改变测量、prepend 锚定、sticky composer、流式 resize 跟随和语义滚动恢复。目录在不改变这些既有约定的前提下提供有界渲染。

**发布可选的第三方目录插件。** 对默认产品否决，因为完整历史路由、行锚点身份、活跃滚动归属与不遮挡布局都已由内置 conversation 包拥有。现有社区实现为轻量索引和链式加载模式提供了参考，但不是运行时依赖。

## 后果

打开已有会话时会启动一次额外的完整历史串行读取。响应数据保持轻量，但历史请求数量会随会话长度增长。现有 Host 分页、授权与 subagent address 检查仍是唯一数据权威；没有引入新的 RPC 或持久索引。

跳转到未加载目标会有意扩展普通正文窗口，因此新增行会像读者点击了「加载更早」一样保留。目录本身的 DOM 大小不随项目总数增长。

隐藏、展开、活跃项目与进行中跳转都是会话视图内存状态，不会跨页面重载持久化。跨会话搜索、书签和完整正文虚拟化仍是独立能力。

## 测试

`conversation-outline.client.spec.ts` 固定摘要上限、角色筛选、普通会话完整分页、已寻址 subagent 路由、排序与实时摘要覆盖。`conversation-outline-view.client.spec.tsx` 固定 500 项目录的有界 DOM 渲染、当前行语义、隐藏／恢复行为，以及指针离开不收起和显式收起控件。`chat-view.client.spec.tsx` 固定从目录选择未加载目标，经 `loadOlder()` 到按渲染序列平滑滚动、面板自动收起与目标行高亮的完整路径。`apply-inject.client.spec.tsx` 固定普通历史注入。无密钥的构建产物测试 `conversation-outline.snapshot.ts` 打开组装后的 75 轮 fixture，确认完整索引超过初始正文窗口，并通过链式分页选择第零轮，直到对应行挂载并完成滚动。
